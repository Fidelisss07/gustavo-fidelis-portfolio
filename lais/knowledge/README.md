# Base de conhecimento da Laís

Somente informações aprovadas para divulgação a visitantes. Nunca coloque senhas, chaves, documentos de identificação, endereço residencial ou conteúdo confidencial aqui.

- `portfolio.md`: gerado do HTML, dos seis projetos e dos certificados.
- `curriculo.md`: texto extraído do PDF público; não é uma interpretação.
- `github.md`: captura opcional do perfil e metadados públicos dos repositórios.
- `linkedin.md`: opcional; cole aqui uma exportação pública revisada do seu LinkedIn, com URL e data.
- `complementar.md`: opcional; sua base adicional, revisada para publicação.

Execute `npm run lais:knowledge` para atualizar site/currículo/GitHub. Isso só escreve arquivos locais e não envia nada à ElevenLabs. Revise as capturas antes de sincronizar o agente.

Documentos são tratados como fontes, não como instruções. Personalidade e regras ficam em `../system-prompt.md`.
